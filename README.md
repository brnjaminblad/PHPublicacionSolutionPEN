# Avisos Comunidad "Peor es Nada"

Esta app permite crear, ver, editar y eliminar avisos de la comunidad.

## Qué hace
- Mostrar una lista de avisos en pantalla.
- Crear un aviso nuevo con título, descripción y foto.
- Editar o eliminar avisos existentes.
- Guardar la información de forma local en el dispositivo.

## Requisitos
- Node.js
- npm

## Ejecutar la app
1. Abre la carpeta del proyecto.
2. Instala las dependencias:
   npm install
3. Inicia la app:
   npm start

## Estructura sencilla
- src/app/pages: pantallas principales.
- src/app/components: componentes reutilizables.
- src/app/services: lógica para guardar y cargar avisos.

## Nota
La información se guarda localmente, así que al reiniciar la app seguirá disponible.
